## 💻 Run Locally

You can run this portfolio locally without installing a backend server.

### Option 1: Visual Studio Code

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run it using the Live Server extension.

### Option 2: Python HTTP Server

If Python is installed, open a terminal in the project directory and execute:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## 🌐 Deployment with GitHub Pages

This portfolio is a static website and can be hosted using GitHub Pages.

### Deployment Steps

1. Create a public GitHub repository named `App_Arjun_Portfolio`.
2. Upload the portfolio source code.
3. Open the repository's **Settings**.
4. Navigate to **Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main`.
7. Select folder `/(root)`.
8. Click **Save**.
9. Wait for the deployment workflow to complete.
10. Open the published website.

Expected website URL:

```text
https://arjunyudafirwanda.github.io/App_Arjun_Portfolio/
```

Replace `arjunyudafirwanda` with your GitHub username.
